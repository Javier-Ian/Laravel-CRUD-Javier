A modern and comprehensive web-based enrollment management system built with Laravel and Soft UI Dashboard. Streamline your educational institution's enrollment process with an intuitive interface and powerful features.

## ✨ Features

### Core Functionality
- 🔐 Secure User Authentication & Role-based Authorization
- 👥 Comprehensive Student Management
- 📋 Course/Program Administration
- 📝 Enrollment Processing & Tracking
- 📊 Academic Records Management

### User Interface
- 🎨 Modern Soft UI Dashboard Design
- 📱 Fully Responsive Layout
- 🌙 Light/Dark Mode Support
- 📊 Interactive Data Tables
- 🎯 Intuitive Navigation

### Security & Performance
- 🛡️ Advanced Data Validation
- 🔒 CSRF Protection
- ⚡ Optimized Database Queries
- 📈 Real-time Updates

## 🛠️ Tech Stack

### Backend
- **Framework:** Laravel 10.x
- **PHP Version:** 8.0+
- **Database:** MySQL
- **Authentication:** Laravel Breeze
- **API:** RESTful Architecture

### Frontend
- **Template Engine:** Blade
- **Styling:** 
  - SCSS/CSS3
  - Soft UI Dashboard Theme
  - Tailwind CSS
- **JavaScript:** 
  - Vanilla JS
  - Alpine.js
- **Icons:** Font Awesome 6

## 📋 Requirements

- PHP >= 8.0
- Composer
- Node.js & NPM
- MySQL >= 5.7
- Web Server (Apache/Nginx)
